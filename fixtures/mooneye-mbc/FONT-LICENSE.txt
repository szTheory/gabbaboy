The pinned Mooneye source identifies its bundled `common/font.bin` as an
8x8 ASCII bitmap font by Darkrose and links to an OpenGameArt asset page, but
the pinned repository contains no font source or font-specific license.
That artwork is therefore not redistributed here.

The ROMs in this directory were assembled with a 2032-byte all-zero asset
generated by the project-authored `font-source.c`. It preserves the include
size and ROM layout. It contains no font glyphs and does not change any
hardware-test instructions, assertions, or pass/fail protocol. The replacement
is original project material under the repository MIT license.
