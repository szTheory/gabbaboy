# Mooneye CPU/timer candidate eligibility audit

## Immutable identity and rights

Source is Mooneye Test Suite commit `31510e12eea6286d36eea060a6adde755e1067aa`, tree `2b8c52424a49a2a7466cf631fd8992c53d0de2fa`. The source and helper files carry the upstream MIT notice, retained in `LICENSE.txt`; the candidate patch retains those headers. WLA-DX is the separately pinned GPL-2.0-or-later build tool in `SOURCES.md`, not part of the ROM. The upstream Darkrose `common/font.bin` has no supplied redistribution license. Preparation substitutes only the documented 2032-byte zero asset from `font-source.c`, digest `23ba65cb93433b65e7ddcae5f8a7dd2ca232491793848644e625875c6dd6ae43`; see `FONT-LICENSE.txt`.

## Source and execution closure

The three acceptance roots are `acceptance/instr/daa.s`, `acceptance/timer/tim00.s`, and `acceptance/timer/tim00_div_trigger.s`. Each includes `common.s`, which includes `hardware.s`, `macros.s`, and the exact `common/lib/*.s` list in its `manifest.json` `source_closure`. `common.s` also includes `font.bin`. No root includes other files directly. Its header selects `.romdmg` by default, jumps from `$100` to `$150`, and enters the test with boot ROM skipped; none of the three roots asserts boot-state or CGB behavior. Each source explicitly declares pass on DMG hardware. DAA compares all table-defined DAA output and flag cases. The two timer roots compare sampled TIMA values with independent source constants `$04` and `$05` after controlled DIV/TAC operations. There is no PPU read in the assertion bodies.

All three **checked-in ROMs are ineligible as built** for this phase's CPU/timer-only core. Both timer roots run `setup_assertions`, set expected D/E, then `quit_check_asserts` selects `check_asserts_cb`. DAA uses `quit_ok` after both table loops, or `quit_inline` from its real mismatch branch. Both macro paths jump to `quit`, which calls `is_ppu_broken` **before** invoking the callback. `is_ppu_broken` reads LY (`FF44`). The original `quit` can then call `disable_ppu_safe`, `reset_screen`, and `print_load_font` (LCDC/PPU registers and VRAM); it passes HL=`$9800` to printing callbacks, then reads LY again and waits on LY during post-callback reporting. These accesses make even an otherwise correct assertion result depend on missing PPU behavior. A generic unsupported-read fallback cannot qualify these ROMs.

The source-only derivative may modify only harness `common/common.s` and `common/lib/quit.s`: remove PPU-only included helper sections and unused font section, invoke the original callback directly with a WRAM print pointer (`$c000`), then preserve returned D status. The timer callback's original `check_asserts_cb` still compares saved registers with source constants and returns D=0 for pass or nonzero for failure. DAA's original inline callbacks still set D=`$00` or `$42` after the table checks. The unchanged `quit` verdict maps D=0 to B,C,D,E,H,L=`03 05 08 0d 15 22` and nonzero D to six `$42` bytes, then executes the original `magic_breakpoint` (`LD B,B`, opcode `$40`). Serial handling follows the breakpoint. No PPU bus access is required before that point. The candidate probe must confirm the path and fail closed if it cannot.

The derived source is **not** an untouched upstream hardware ROM, and no manifest entry, checked-in ROM, or fixed denominator changes in this plan. Cross-host WLA-DX byte reproduction remains open as described in `SOURCES.md`; any candidate needs its own pinned patch digest and ROM identity. T-02-25, CR-05 and T-02-15 remain open until positive and deliberately failing protocol probes pass and the final admitted suite is verified.
