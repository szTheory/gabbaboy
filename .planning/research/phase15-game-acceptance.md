## Phase 15 CGB game acceptance route

| Option | Pros | Cons | Complexity | Recommendation |
|--------|------|------|------------|----------------|
| Rebound native-CGB acceptance, with one strict admission gate | CGB-only MBC5 without save RAM; small title; upstream RGBDS/Python build recipe; source exposes coin and level/screen state that could support a game-native predicate | Repository MIT label does not establish every asset’s provenance; build tool versions are unpinned; archived source; the known candidate ROM digest is not yet tied to the current source pin; no scripted progress or CGB audio/frame run has been demonstrated | New native-CGB runner case and predicate/ROM anchors, RGB555 and PCM receipts, manifest/notices and automated controls -- Risk: rights/build closure and false-positive progress | Rec if exact-source rebuild and all asset records close, and meaningful input reaches a stable in-game predicate that controls reject |
| Explicit no-CGB-game-evidence ledger entry | Satisfies CGB-11 without admitting a doubtful fixture; preserves honest release claims; avoids expanding acceptance into a new renderer or broad game hunt | Provides no CGB gameplay evidence | Support-ledger statement plus a contract check -- Risk: later docs accidentally imply game-level support | Rec if any rights, reproducibility, predicate, or native-CGB runner gate remains open at the phase cutoff |

**Rationale:** Keep the candidate attempt to Rebound at upstream HEAD `cc2966e1643d480d0780fb6cc5b9ef53d5ef6898`: its [README/build instructions](https://github.com/DevEd2/Rebound/blob/cc2966e1643d480d0780fb6cc5b9ef53d5ef6898/README.md), [MIT license](https://github.com/DevEd2/Rebound/blob/cc2966e1643d480d0780fb6cc5b9ef53d5ef6898/LICENSE), [level state](https://github.com/DevEd2/Rebound/blob/cc2966e1643d480d0780fb6cc5b9ef53d5ef6898/Engine/GameModes/Level.asm), and [player coin counter](https://github.com/DevEd2/Rebound/blob/cc2966e1643d480d0780fb6cc5b9ef53d5ef6898/Engine/Player.asm) make a narrow proof-of-feasibility plausible, but neither the repository-wide license nor the code inspection closes the required per-asset manifest. Before admission, bind a reproducible build and digest to that exact source/toolchain, verify assets, and prove a native-CGB script reaches a game-native objective: false in title/attract and on passive movement, true only after meaningful scripted play, stable across two consecutive frame boundaries, while no-input and wrong-input runs fail at the same emulated-time budget. This requires a bounded CGB-specific runner/predicate path: the Phase 7 [GAME-02 contract](../../docs/game-acceptance.md) is Libbet/DMG-frame bound, and the current progress capture cannot simply reuse its predicate or frame path; receipt RGB555 and PCM digests in CGB mode, never DMG compatibility mode. The [v0.2 stack](v0.2/STACK.md) records candidate ROM SHA-256 `195765b8ca3b0fb7d37b7b92d0242d6c7e01ec71f27f93e565fa081e449cbb92`, which still needs reconciliation with this source pin. Rex Runner’s [source](https://github.com/etdv-thevoid/rex-runner-gb/tree/0d9ca631aaa400a1599dcbd03170ba8daf75a1e8) exposes a score/game-state oracle, but its [manifest](https://github.com/etdv-thevoid/rex-runner-gb/blob/0d9ca631aaa400a1599dcbd03170ba8daf75a1e8/.gitmodules) pulls in two separately licensed submodules; GBHack’s [README](https://github.com/statico/gbhack/blob/58bfe384d9f923200fd17289eb11705c6f1ab79a/README.md) describes a 15-floor procedural roguelike and its [RNG](https://github.com/statico/gbhack/blob/58bfe384d9f923200fd17289eb11705c6f1ab79a/src/rng.c) is seeded from the emulated divider, so its gameplay path adds more scope; Aevilia’s [README](https://github.com/ISSOtm/Aevilia-GB/blob/5759e97089aa825e992317327cb850420728b93e/README.md) identifies Apache-2.0 plus a separate DevSound MIT dependency and describes the codebase as unmaintained. These are not reasons to admit those ROMs or widen the candidate search. If Rebound fails any gate, do not admit it or pause for a legal-owner checkpoint: record the permitted explicit absence in the support ledger. Automate the decidable gates and negative controls per D-069; digest receipts are emulator regression observations, not hardware or perceptual evidence. The current [game-acceptance limitation note](../../docs/game-acceptance.md) describes an older dispatch-only reproduction state and should be reconciled only against an actual Phase 15 run.
