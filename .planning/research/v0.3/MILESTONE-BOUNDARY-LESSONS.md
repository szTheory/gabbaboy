## Concise outgoing transfer

numbered player slots and a raw-save/SIGTERM host runner. Three reusable failure
mechanisms are recorded in LESSONS.md: validate all fields before applying state
with one shared non-failing conversion; publish readiness JSON by atomic rename
only after its payload is complete; distinguish immutable Git paths and exact
checkout bytes from host filesystem paths/EOL conversion. Test each at the real
consumer seam with a control that rejects the original defect. These are
software-engineering results for the named source/corpus, not evidence for any
other console, physical hardware or live Playstead integration. This transfer
is prepared locally; it has not been sent or written to another project.
