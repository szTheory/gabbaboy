## Cross-phase integration

A `gsd-integration-checker` subagent checked integration read-only at `f03e9b1`. It configured a scratch CMake build in the scratchpad; it did not compile, run tests or edit the repo. The orchestrator then re-checked the checker's one warning against the source.

- **Public API:** all 14 public `gbb_*` functions declared in `include/gabbaboy/gabbaboy.h` are implemented in `src/core`.
- **Export groups:** all are wired to their callers:
  - lifecycle, load, run and reset
  - framebuffer
  - joypad events
  - battery
  - diagnostics
  - trace and `gbb_run_ex`
  - `gbb_peek_ram`
  - audio PCM
  - the relocated package targets
- **Test inventory:**
  - `tests/expected-tests.txt` lists 184 names and `ctest -N` registers 179.
  - The 5 extra names are the `installed_*` tests. These register only when `GBB_TEST_INSTALL_PREFIX` is set (`tests/CMakeLists.txt:334-363`), and `.github/scripts/verify-test-inventory.sh` handles them per mode.
  - No test is registered without being listed.
- **Player wiring:**
  - Video and audio come from the main loop (`src/player/main.c:164`).
  - Input goes through `gbb_queue_events` (`src/player/input.c:189,315`).
  - Battery data loads through `gbb_battery_size` and `gbb_import_battery`, and saves through `gbb_copy_battery`.
  - Saves are atomic: temp file, fsync, rename, then directory sync (`src/player/session.c:581-645`). A final save runs on exit (`main.c:2066`).
- **CI and release:**
  - The `required-native` job aggregates the Linux, macOS, Windows, sanitizer, CMake-floor and player-package jobs.
  - `preview.yml` checks for a successful `required-native` run on the exact PR head before its package smoke runs.
  - `release.yml` generates and verifies the support ledger, generates the performance receipt, and runs a fail-closed platform manifest.
- **Checker warning, re-classified:** the checker reported that installed consumers never call `gbb_run_audio`. The orchestrator found that `examples/relocated-c/main.c:180` does call it against the extracted package, inside `preview_package_smoke` (`cmake/PreviewPackageSmoke.cmake:117-143`), which runs on the Linux x64 and macOS arm64 preview lanes. That covers audio through the relocated package for C. The C++ consumer and the Windows lane remain without audio coverage, which is recorded as non-blocking tech debt for AUDIO-02 and SHIP-01.
