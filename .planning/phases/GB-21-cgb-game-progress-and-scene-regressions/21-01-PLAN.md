## Artifacts this phase produces

This plan creates `tests/scripts/verify-cgb-progress.py` with `--self-test`, `--runner`, `--repo-root`, `--source-revision`, and `--tracer` modes; a deterministic 32-KiB original native-CGB ROM builder; the predicates `cgb-control-progress` and `cgb-control-impossible`; `gbb_accept_predicate_eval_fn`; the appended `gbb_accept_predicate.evaluate` and `.observation_policy` fields; observation policies `GBB_ACCEPT_OBSERVE_LIBBET` and `GBB_ACCEPT_OBSERVE_PROGRESS_ONLY`; bounded RGB555 stores in `frame_record`/`run_state`; and CTest `acceptance_cgb_progress_tracer`. The ROM is generated only in a temporary test directory and is never installed. Existing public ABI and case-file syntax are sufficient.

<interfaces>
The original positive callback requires C000==0xA5 and C001==0x01. The impossible callback uses the same pinned ROM and anchors but requires C001==0xFF, which the authored control cannot produce (its source permits only 0 and 1). New predicate callbacks and observation policies are internal immutable metadata; legacy records retain a null callback and the zero-valued Libbet policy. No public ABI or case parser change is required.
</interfaces>
