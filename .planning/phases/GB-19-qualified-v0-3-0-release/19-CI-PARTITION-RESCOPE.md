It authorizes one additional consolidated test-harness implementation/review cycle; earlier rounds and failed attempts remain recorded, never reset.

1. **Parity by model.** Split only the existing outer DMG/CGB dimension into separately registered checks. Each retains all cartridge/ROM/RAM/length/checksum/header combinations, real `gbb_probe_rom` versus real `gbb_load_rom`, refusal non-mutation assertions, the independent CGB oracle and the PGB/checksum negative control. Keep existing release optimization and fixed timeout. Run these two checks serially so each has an isolated bounded work unit.
2. **Post-tag controls by meaning.** Use the existing trust wiring, capture/source proof, draft assets, recovery/checksums, downstream consumption and final publication families as independently runnable groups. Preserve every current assertion, positive baseline, mutation/refusal case and structural endpoint-inventory check. Keep the production lifecycle/gates unchanged and every group's current 60-second timeout; serialize the groups. Keep the legacy lifecycle controls intact.
3. **Coverage as a contract.** Assign stable IDs to existing emitted control units, including cases inside composite functions. Validate exact, duplicate-free registration, complete and disjoint partition union, and executed IDs against `tests/data/release-lifecycle-post-tag-coverage.json` at baseline revision `dcb2c92668a47bc04f88fd3c57bc0d2e978473e1`, loaded by `git show <rev>:<path>`. Its versioned schema records ordered `{id, group}` rows. The lifecycle CLI keeps `--self-test-post-tag` for all six groups and adds `--self-test-post-tag-group` and `--self-test-post-tag-coverage`. Each group prints its stable ID digest and individual `post-tag-control PASS <id>` lines; only `trust` reports `endpoint_inventory=pass`, while other groups report `endpoint_inventory=not-in-group`. The coverage mode refuses omitted, duplicated and wrong-group registrations. For parity, verify complete/disjoint model registration and retain all original matrix inputs/oracles. Numeric totals or a faster run alone cannot establish coverage preservation.

Serialize each parity and lifecycle partition with its existing fixed timeout. Update CMake registrations, exact expected inventory and both Windows POSIX exclusion inventories together.
