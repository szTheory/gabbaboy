## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| save file on disk -> decode_save_v2 | Untrusted, possibly corrupt or crafted envelope |
| host clock -> saved_at | Host time written into the file |
| player -> filesystem | Atomic replace in the per-user directory |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-24 | Denial of service | v2 lengths | high | mitigate | ram_len and rtc_len allow-lists checked before addition; total in uint64_t; exact file size; heap buffer of that exact size; player_session_v2_max_size |
| T-09-25 | Tampering | saved_at injection | medium | mitigate | CRC-32 covers the header including saved_at (accident detection, documented as not authentication); worst case is a bounded modular catch-up |
| T-09-26 | Tampering | partial write / crash | high | mitigate | Existing atomic same-directory replace; seven v2 fault tests prove the old file survives and loads |
| T-09-27 | Tampering | classification drift | medium | mitigate | Classification only from the core; 1536-case drift sweep |
| T-09-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager install in this plan |
</threat_model>
