## Sampling Rate

- **After each checker change:** Run the directly affected immutable report/handoff contract and the production-path self-test with causal negative controls.
- **Before CTest:** Run the direct self-test and stage checks first; configure the existing `phase1` preset, then run only `plan_cap` and `planning_hygiene_controls`.
- **Before phase closure:** Rebind checks to the final committed revision; run the two named CTests once at that final head, plus required summary-coverage and shared UAT-closure checks.
- **Stopped:** Do not run the broad local suite, a third local lifecycle retest, or D-103's exact-final-head milestone suite. No release lifecycle command is in scope.
