### CR-01: YAML-equivalent root key spellings

| Option | Description | Selected |
|--------|-------------|----------|
| Canonical fixed-schema scanner | Preserve raw pairs and accept only the exact `requirements:` root spelling; reject equivalent whitespace, quoted, escaped, tab-separated, and explicit-key aliases. | ✓ |
| Broader YAML key canonicalizer | Normalize supported plain and quoted scalar keys before duplicate checks. | |

| Option | Description | Selected |

A full parser adds dependency and source-span complexity for a fixed top-level contract; rejecting all comments would unnecessarily prohibit harmless visible comments.
