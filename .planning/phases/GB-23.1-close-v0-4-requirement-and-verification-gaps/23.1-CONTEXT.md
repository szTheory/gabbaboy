- D-196 advisory fan-out covered YAML key parsing and adversarial syntax, Markdown comment/code precedence and source masking, plus owner/QA boundary checks. Recommendation: keep the fixed contract dependency-free; reject YAML-equivalent root aliases before dictionary construction and use one line-preserving comment-aware mask with code regions shielded. The exact CLI-mutant matrix and one-review stop are recorded in D-09–D-11.
- Official sources: [YAML 1.2.2](https://yaml.org/spec/1.2.2/) shows mapping keys are semantically unique, separation whitespace is presentation syntax, and quoted keys are valid; [CommonMark 0.31.2](https://spec.commonmark.org/0.31.2/) defines code-fence matching/unclosed behavior, HTML comments, and inline code-span delimiters.
