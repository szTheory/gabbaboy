## Narrative Findings (AI reviewer)

### CR-01: YAML-equivalent duplicate requirements root bypasses duplicate retention

**Classification:** BLOCKER (Critical)

**File:** `tests/scripts/verify-planning-hygiene.py:297-327, 378-411, 607-618`
**Issue:** The root-map check recognizes only the exact line `requirements:`, while `frontmatter_duplicates()` recognizes a top-level key only when the colon immediately follows the unquoted key. A second YAML key spelled `requirements :` (or a quoted equivalent) is therefore missed as a duplicate. `frontmatter_mapping_pairs()` reads the first map and stops at the second root line, so it still returns the four valid `pending` pairs; a YAML frontmatter reader treats the alternate spelling as the same key and may take the contradictory second map. The report can pass this checker while its parsed requirement map contradicts the separately validated Pending dispositions. The causal controls cover an exact duplicate spelling but not an equivalent YAML key spelling.
**Fix:** Enforce the fixed frontmatter key grammar across every root line and reject alternate spellings that normalize to `requirements`; retain duplicate detection over canonicalized root keys. Add a production-CLI negative with a second `requirements :` map containing a contradictory value.

### CR-02: HTML comments can supply hidden protected headings and section bodies

**Classification:** BLOCKER (Critical)

**File:** `tests/scripts/verify-planning-hygiene.py:414-436, 439-455, 574-575, 653-716, 739-790`
**Issue:** `visible_markdown_lines()` masks fenced and indented code but leaves HTML comments untouched. As a result, a protected heading and its required table or facts inside a multiline `<!-- ... -->` comment remain visible to `markdown_heading_count()`, `markdown_section()`, and the global report checks. Hidden report links and STATE/PROJECT/continuation handoff text also remain available to the corresponding checks. A document can therefore hide required contract content from rendered readers while the immutable report or handoff checker accepts it. Existing causal controls cover fenced and indented code but do not cover HTML comments.
**Fix:** Extend the shared line-preserving mask to hide HTML comment spans, including multiline and unclosed comments, before heading counting, section extraction, Setext scanning, global fact checks, and link checks. Add production-CLI negatives that place required headings and bodies inside comments for the report and each handoff surface.
