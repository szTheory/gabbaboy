Write cmake/VerifyDmgBaseline.cmake (valid at CMake 3.25, script mode) with inputs GBB_MODE (check | print-candidate | junit), GBB_SOURCE_DIR, GBB_LEDGER (default tests/baseline/dmg-cpu-b-v1.txt), GBB_CHANGES (default tests/baseline/CHANGES.md), GBB_RUNNER, GBB_MEASURE, optional GBB_OBSERVED (a file of key<TAB>value lines that replaces live collection, used by self-tests), GBB_JUNIT and GBB_INVENTORY (core | player) for junit mode.

Observation collection (when GBB_OBSERVED is absent): run, with WORKING_DIRECTORY GBB_SOURCE_DIR, the runner with --acceptance tests/acceptance/cases.txt --case libbet --observe and with --manifest fixtures/mooneye/manifest.json --suite --observe, and GBB_MEASURE --no-trace fixtures/tracer/tracer.gb (record bench.tracer.correctness_digest_fnv1a64 from its correctness_digest_fnv1a64 field and bench.tracer.workload from its workload field); any non-zero exit is a failure. Strip carriage returns from every line read. Inventory observations are the lines of tests/expected-tests.txt (inventory.core.<name>) and tests/player/expected-tests.txt (inventory.player.<name>) with value frozen, plus inventory.sha256 = SHA-256 over the LF-joined sorted inventory.core and inventory.player keys (provenance only; see must_haves).

check mode, in this order and printing exactly one line per category ("baseline inventory=ok|fail <detail>", then mooneye, acceptance, bench, changes, then "baseline status=pass|fail"): reject an empty ledger (empty-ledger), a line without exactly one tab (malformed-line), a duplicate key (duplicate-key), lines not in byte order (unsorted-ledger), missing or invalid header keys schema/model/frozen_revision/frozen_date/frozen_body_sha256/coverage (header-invalid); require at least one ledger line in each frozen section (empty-section) and a non-empty observation set (empty-observations); for mooneye., acceptance. and bench. keys except bench.advisory.*, report modified (value differs), missing (ledger key not observed) and extra (observed key not in the ledger); for inventory, report removed when a frozen inventory.core or inventory.player name is not observed (new names allowed; inventory.sha256 skipped). Parse CHANGES.md table rows of the form | key | old | new | reason | evidence class and citation | approver |; reject a row whose old equals new (changes-noop) or whose new does not equal the current ledger value (changes-inconsistent); reverse-apply rows newest first to the ledger body (all keys except the six header keys), join with LF, hash with string(SHA256) and fail with unrecorded-change unless it equals frozen_body_sha256. End with FATAL_ERROR on any failure.

print-candidate mode emits a complete candidate ledger (header keys with frozen_revision from git rev-parse HEAD in GBB_SOURCE_DIR, frozen_date in UTC, frozen_body_sha256 computed over the candidate body, a coverage placeholder line the freeze replaces, then all observations), sorted, to standard output only (for example via execute_process of ${CMAKE_COMMAND} -E cat on a file inside a temporary directory that is removed afterwards); it never writes GBB_LEDGER.

Write tests/scripts/verify-dmg-baseline.sh (bash, set -euo pipefail): options --build-dir DIR (default build), --print-candidate, --junit FILE --inventory core|player; it locates gabbaboy-runner and measure_core (with .exe on Windows) in the build directory and runs cmake -P with the matching GBB_MODE; with no option it runs check mode. It contains no comparison logic of its own.

Create self-test fixtures (LF via the tests/baseline/** rule from Plan 07-01): tests/baseline/selftest/observed.txt (a small synthetic observation set covering every section, including inventory.sha256), tests/baseline/selftest/ledger.txt (a matching sorted ledger whose frozen_body_sha256 is correct), tests/baseline/selftest/CHANGES.md (protocol header and one valid row used only by the changes_recorded variant).
