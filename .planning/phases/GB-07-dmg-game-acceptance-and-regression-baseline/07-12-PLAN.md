Add src/player/script_smoke.c and script_smoke.h to gabbaboy-player-adapter and link the adapter PUBLIC to gabbaboy_accept. The module exposes a prepare step and a run step. Prepare (no state mutation): read the script with a 65536-byte bounded read in rb mode and parse it with gbb_accept_script_parse; read the ROM with an 8 MiB bounded read; compute its SHA-256 and look up the predicate with gbb_accept_predicate_find("libbet-tutorial-cleared", digest) (unknown digest is an error); any failure returns a message and leaves the player untouched. Run: load the ROM through the existing session load path, then call gbb_accept_drive with budget 505612800, tail 8388608 (the runner's stopping rule), max_batch 56, a deliver callback, and a PCM sink that feeds gbb_accept_pcm_digest_feed and gbb_accept_pcm_stats (window from play_start) before handing each frame to player_audio_submit. The deliver callback contract is (ctx, events, count) with gbb_input_event press/release kinds and absolute at_half_dots. In main.c the callback converts each button with the same mapping the keyboard uses (RIGHT/LEFT/UP/DOWN arrows, A Z, B X, START Return, SELECT Right Shift), computes the exact timestamp host_anchor_ns + ns(at_half_dots - anchor half-dots) with player_input_half_dots_to_nanoseconds and overflow checks (no +8 skew), pushes the SDL key event and pumps events so it is handled by the normal keyboard handler and player_input_key.

In main.c add the 5-argument shape --smoke-package <invalid-rom> --input-script <script> <rom> to both the package_smoke boolean and the usage guard, update the usage string and print_player_help (diagnostic section, next to --smoke-package), and dispatch to the scripted smoke (it does not run the demo/battery package checks; those keep their existing argc 3 path). Print exactly one line smoke_report rom_sha256=<hex> half_dots=<T_hit> predicate=pass pcm_nonsilent=1 pcm_sha256=<hex> and exit 0 on pass; on predicate miss print smoke_report ... predicate=fail ... and exit 1; on bad input print the parse or load error and exit 2. No save files, no environment-variable activation, no network (D-38).
