|----------|-------------|
| host ROM bytes -> validate_header | Untrusted header and length enter the loader |
| guest writes -> mapper registers / RAM window | Guest-controlled bank and enable values index host memory |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-01 | Tampering | validate_header table lookup | high | mitigate | Row lookup only after size >= 0x150; rom_size_code > row max rejected before the 32768u << code shift; precedence identical (D-05); proven by 86,016-cell differential and loader_boundary_fuzz |
| T-08-02 | Tampering | gbb_load_rom allocation order | high | mitigate | Validate, allocate, commit unchanged; cart_state committed only after allocation succeeds; loader_non_destructive and the differential's previous-ROM read check failed loads leave state intact |
