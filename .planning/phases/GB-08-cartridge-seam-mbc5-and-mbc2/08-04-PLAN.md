Keep player users' data honest once the core accepts MBC2 and MBC5 battery cartridges (D-22): those types run without persistence, the player says so in its status and on stderr, never touches the save directory for them, and the limitations text states the gap. Output: battery_unsupported identity flag, status/warning branches, updated limitations text and its byte-for-byte test, a new player session test.
Parallelism: runs in the same wave as Plan 08-05; the two plans share no file.
</objective>
