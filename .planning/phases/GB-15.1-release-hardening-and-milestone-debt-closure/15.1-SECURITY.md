# Phase 15.1 Security Review (STRIDE, ASVS level 1)

Surfaces: release and rehearsal workflows, release evidence producers, trusted judge and attacher, bounded downloader, source-archive and delivery verifiers, ROM-facing acceptance input queue, and the new closeout checker. Method: the executing agent traced each surface and ran the controls listed in `15.1-REVIEW.md`. It is not an independent security reviewer (see the independence statement there).

| Threat | Category | Component | Mitigation observed | Status |
|---|---|---|---|---|
| T-15.1-17 | Tampering | `15.1-DISPOSITIONS.json` | Scope digest, immutable audit-commit text, evidence digests, shipped-release constants; 30 CLI rejection controls | Mitigated |
| T-15.1-SC | Tampering | Package installation | No dependency or package was added in this plan; no install was run | Mitigated |
| S1 | Spoofing | Hosted identity | Hosted claims must equal run, attempt, head and job conclusions read through `gh api`; a receipt label is rejected | Mitigated |
| T1 | Tampering | Release workflow inputs | `inputs.*` reach shell only through `env:`; no `pull_request_target`; `actionlint` clean | Mitigated |
| T2 | Tampering | Source-executing evidence jobs | Corpus, fuzz and performance producers are read-only and have no persisted credential; the judge and attacher run from a trusted checkout | Mitigated, with five write jobs as a named residual (`LIM-RESIDUAL-WRITE-JOBS`) |
| R1 | Repudiation | Merge authority | The phase-pr receipt binds PR, exact head and required check runs read from the API; skipped, stale, foreign or old-attempt runs are rejected | Mitigated |
| I1 | Information disclosure | Retained diagnostics and records | Retained text is sanitized for host paths, user names and token shapes; no secret was read or printed | Mitigated |
| D1 | Denial of service | Downloads | Byte, total-time, stall and redirect bounds; credentials never leave the first origin | Mitigated |
| D2 | Denial of service | Acceptance input | The bounded queue drains dense same-time spans without growing; mutant without refill is rejected | Mitigated |
| E1 | Elevation | Branch protection | Not bypassed; strict, admin-enforced protection is respected | Mitigated |

## Findings

No Critical or High findings. Open items are the named residuals (`LIM-RESIDUAL-WRITE-JOBS`, `LIM-TRUSTED-JUDGE`) and the non-independent reviewer (R-01), none of which is a counted pass. No release, tag or published asset was touched. `/gsd-secure-phase 15.1` remains available for a separate audit.
