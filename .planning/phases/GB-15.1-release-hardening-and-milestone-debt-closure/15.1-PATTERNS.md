```python

    def run_cli(self, *args: str) -> subprocess.CompletedProcess[str]:
        return subprocess.run(
            [sys.executable, "-I", str(SCRIPT), *args], cwd=ROOT,
            text=True, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, check=False,
        )

    def verify_rejects(self, path: Path, payload: dict[str, object], reason: str) -> None:
        path.write_text(json.dumps(payload), encoding="utf-8")
        result = self.run_cli("--verify", str(path))
        self.assertNotEqual(result.returncode, 0, f"production verifier accepted negative receipt: {reason}")
        self.assertIn(reason, result.stdout, f"wrong rejection reason for negative receipt: {result.stdout}")
```

## Shared Patterns

1. **Actual entry point and intended failure:** use A/B CLI subprocess tests, check nonzero exit plus intended diagnostic, verify failed output is not left as a success receipt. Start with the forged/unbound source-receipt tracer before broad refactors.
2. **Independent identity:** A's explicit Git object lookup and E's exact inventory compare apply to archive/consumer/ledger/delivery. Bind observed bytes and control-plane facts separately from producer claims. Preserve schema meaning or version new fields; do not compare a prefix digest to a tarball digest.
3. **Explicit owners and roots:** B's source manifest is a reference for revision-bound inputs; trusted validator code and qualified source must have separate roots throughout delegates/imports. The subject checkout may never select a weaker judge. Producer jobs are unprivileged; minimal attacher/recovery operates only on qualified retained bytes.
4. **Bounded work and retained errors:** C guards progress; A bounds members/bytes; B bounds campaign/diagnostics. Apply connection/total timeouts and streamed byte accounting to real downloads. Test oversized unknown-length/chunked and stalled HTTP responses with cleanup and credential-safe redirects. Modern curl version behavior must be verified rather than assuming every unknown-length response bypasses `--max-filesize`.
5. **Historical fidelity:** D migrates representation, E preserves qualified bytes, B preserves producer identity. Per-ID disposition must distinguish repaired defect, qualified advisory, fresh evidence, historical unknown and external limitation. None of these is implicit owner acceptance.
6. **Small integration surface:** one owner coordinates workflows, CMake registrations, expected inventory and trust-root interfaces. Independent archive/native/metadata work can proceed with those seams fixed. Final full suites, affected frozen DMG checks, independent review/security and exact-head hosted required checks remain execution gates.
