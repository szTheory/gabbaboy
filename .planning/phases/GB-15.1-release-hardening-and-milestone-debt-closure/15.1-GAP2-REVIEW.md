- **Token-step command judge** (`verify-workflow-policy.py`). I ran about 28 probe scripts through `_token_step_commands` and `_token_command_allowed`. Everything not on the allowlist was reported, or rejected fail-closed. That includes the `[[ ]]` skip logic, assignment prefixes, function bodies, `$(...)`, backticks and `${x:-$(...)}` nesting, `$((...))`, and unquoted heredocs. The `head_read_contract_mutant` control asserts both a fail-open on the weak source and a rejection of the conforming one, so it can fail.

- **expect_exit min-count** (`expect_exit.cmake` and its CMake tests). The rejecting control uses `PASS_REGULAR_EXPRESSION` on the exact error text, so it can only pass through the minimum check. `LESS` with variable names resolves correctly.
- **Consumers NFKC** (`verify-v02-consumers.py`). NFKC folds `COM¹` to `COM1`, `CONIN$` and `CONOUT$` are included, and the new tar-member cases cover them.
- **Closeout scan** (`verify-closeout-scan.py`). A `GSD_TOOLS` value that is not a file now fails with exit 3. The decoy-marker test proves the fallback runtime never runs.

## Info

### GR2-IN-01: Fuzz self-test control counts are hand-written literals the CMake regex cannot check

**File:** `tests/scripts/verify-v02-fuzz.py:1884` (also `tests/CMakeLists.txt:1418`)

**Issue:** `self_test` prints `positive_controls=5 negative_controls={22 + 14 + 5}` from literals, not from the executed tests. The CMake contract accepts any `[1-9][0-9]*` for both numbers, so a control that is added, deleted or skipped without updating the literal cannot fail the contract. Individual `assertEqual`s do fail on a real regression, so this is an inventory-accuracy gap, not a hole in the checks. The pattern existed before this diff (`22 + 14`), and the diff extended it by hand. Skips are at least reported through `skipped=`.

**Fix:** Either count the `negative-control=` and `positive-control=` lines printed by the run and assert them against the literal, or pin the exact numbers in the CMake regex the way `uat_closure_controls` now pins a parsed minimum.
