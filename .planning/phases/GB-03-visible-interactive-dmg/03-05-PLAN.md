## Flagged assumptions and timing contract

- SDL is optional and stays out of the default C17 core/test dependency graph. Provision exactly SDL3 3.4.18 from the official immutable release only after verifying its published digest; no network fetch occurs in default configure.
- Core APIs remain one-caller-per-instance. The SDL event loop owns queue admission and progression; callbacks copy their data and never mutate the core.
- Convert elapsed host nanoseconds to half-dots using the profile's named half-dot rate and checked quotient/remainder arithmetic: q = ns / 1,000,000,000; r = ns % 1,000,000,000; ticks = checked(q * rate) + checked(r * rate / 1,000,000,000). Do not multiply an arbitrary 64-bit timestamp directly by the rate.
- Anchor host time to the player's emulated cursor when a session starts. Pause freezes the guest; resume rebases the host anchor to the current guest cursor and discards events that occurred while paused. Reset clears held/pending input and reanchors after core reset. Events that map before the next schedulable guest time are clamped to that time in SDL arrival order; overflow pauses input and produces an actionable error.
- The adapter alone admits player inputs, tracks outstanding queued events from submissions and consumed run time, and caps normal outstanding events at 56 of the core's 64 slots. The remaining eight slots are reserved for releases on focus loss. Queue saturation at the configured cap is tested. If an unexpected admission error still occurs, retain a release-pending mask and prohibit resume until public-API release admission succeeds.
