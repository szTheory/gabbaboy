**ROM image + checksum pattern** (cpp:7-18):
```cpp

    uint8_t rom[rom_bytes]{};
    rom[0x147u] = 0x03u;
    ...
```

**Locals-before-`goto` + cleanup pattern** (cpp:20-26, 48-53). All locals are declared before the first `goto done` (mandatory in C++; copy that discipline into the C file too so the two stay structurally identical, though the C analog interleaves declarations):
