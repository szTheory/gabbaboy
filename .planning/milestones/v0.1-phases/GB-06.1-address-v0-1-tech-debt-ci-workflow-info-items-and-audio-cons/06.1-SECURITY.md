## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| installed package -> consumer | Consumers link only the installed public header and static library | public API calls, PCM buffers |
| user-selected path -> player adapter | A ROM path may name a FIFO, device, terminal or symlink | untrusted file path and bytes |
| verifier -> output directory | Publishing verified artifacts into a possibly shared temp directory | build artifacts and receipts |
| GitHub API JSON -> exact-head gate | Run and job data are untrusted; types and names are checked exactly | CI run metadata |
| workflow event payload -> gate argv | PR head SHA and repo validated before any fetch | SHA / repo strings |
| PR-controlled workflow -> runner | `pull_request` runs PR YAML with a read-only token | read-only GITHUB_TOKEN |
| executor -> protected main | Merges are the only privileged action, under strict protection | merge commits |
| refreshed report -> milestone gate | Verification freshness feeds the milestone audit | planning documents |
