## Phase Goal

**As a** native-library developer, **I want to** build and run an original Game Boy tracer through an installable bounded core, **so that** I can embed and inspect real guest execution.

<objective>
Establish the production-quality vertical slice: a deterministic DMG-CPU-B profile, original guest ROM, instance-owned C API, real CPU/bus RAM round-trip, headless outcome protocol, and bounded trace.

Purpose: prove the project's core architectural path using a guest-authored result.
Output: a local CMake/Ninja/CTest build and runnable tracer whose contract stays inside BASE-01/02/04/05.
</objective>

## Artifacts this phase produces

- Native core and headless runner, C17 public header, original authored ROM and manifest.
- CTest inventory, loader/lifecycle/tracer controls, C/C++ installed consumer projects.
- Schema-6 CMake presets (minimum 3.25), install/export package, native CI and sanitizer gates, fixture regeneration check, revision-linked Linux x64/macOS arm64 preview workflow.
- Build, API, support-limit, PR workflow, artifact retention, and evidence documentation.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Caller to core API | Caller controls profile, ROM pointer/length, run budget, and trace buffer/capacity. |
| Guest ROM to CPU/bus | Guest bytes and execution can exercise only explicitly supported instructions and mapped memory. |
| Runner to fixture file | Host file contents are untrusted until size/type/header checks pass. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-GB01-01 | Tampering | ROM/header parsing | high | mitigate | Validate pointer/length, maximum size, header and ROM-only type before state mutation; test malformed inputs in Plan 02. |
| T-GB01-02 | Denial of Service | Run/trace | high | mitigate | Enforce strict uint64 half-dot budget and fixed caller trace capacity; unsupported and timeout are explicit. |
| T-GB01-03 | Repudiation | Fixture/trace result | medium | mitigate | Bind source, rights, ROM digest, opcode inventory, guest protocol, profile and timeout in manifest. |
| T-GB01-04 | Elevation of Privilege | CI workflow | high | mitigate | In Plan 04 use pull_request, least permissions, pinned action SHAs, and no privileged fork execution. |
| T-GB01-05 | Security controls outside native scope | Web authentication/session/encoding controls | low | accept | ASVS web session controls are not applicable to this local native core; no web service is introduced. |
