Add the one Phase 18 public API change, the read-only `gbb_get_input_clock` getter, so the player can re-anchor input after a slot load (D-24). Prove the struct_size handshake, the post-load semantics, ABI use from both installed consumers, and that state bytes and pins are unchanged.

Purpose: PLAY-01 slot loads restore instance time and up to 64 queued events; without this getter the player cannot queue a release at an admissible time (RESEARCH F6).
Output: header + core function, `tests/test_input_clock.c`, `tests/cmake/input-clock.cmake`, consumer edits, API docs.
</objective>
