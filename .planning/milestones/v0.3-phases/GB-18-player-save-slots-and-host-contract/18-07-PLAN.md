- Real-signal tests set `PROCESSORS 2` (hosted ctest runs 4-wide) and stay under about 25 s each so they remain below 75% of the 60 s base TIMEOUT (GB-CI-012); they keep the base TIMEOUT. The sanitizer flag is passed as `$<$<BOOL:${GABBABOY_ENABLE_SANITIZERS}>:--sanitized>`.
- The harness waits for `gbb-host: ready` with a watchdog (select or a reader thread with a deadline), never an unbounded readline; it resets its own SIGINT/SIGHUP to SIG_DFL before Popen except in the inherited-SIG_IGN row; it signals the child pid directly; it hard-fails (never skips) when `os.geteuid() == 0` for the read-only row; `RLIMIT_CORE=0` via preexec_fn for the storm.
- Decoys are mutant runners built with `gbb_host_mutant_library` + `gbb_host_mutant_runner` (18-02/18-04), exist only in the build tree and are never installed. Test hooks live only under `GBB_HOST_TESTING`.
- Windows build rule (18-01 execution contract, checker B-3), applied here: host_signal.c's POSIX body (`sigaction`, `sigprocmask`, `clock_gettime`, `nanosleep`, `<signal.h>` POSIX parts) sits inside `#ifndef _WIN32`; the `_WIN32` build defines `host_signal_install` (returns 0), `host_signal_stop_requested` (returns 0) and `host_pace_wait` (returns 0) as ISO C stubs, and `host_signal_name` is portable. In host_run.c the paced loop, its CLOCK_MONOTONIC deadline arithmetic and the after-ready hook live in the save-dir path inside `#ifndef _WIN32` (on Windows the D-05 gate returns before it). gbb_host.h declares `host_pace_wait(struct timespec *deadline)` with a forward declaration `struct timespec;`, so it needs no `<time.h>` and compiles on MSVC. `tests/test_host_run.c` and its executable, the four decoy mutant libraries and their `gbb_host_mutant_runner` executables are created inside `if(NOT WIN32)` in tests/cmake/host.cmake next to their `add_test`; the `no_host_clock_signal_seed` library (Task 3) is portable C and stays on every platform.

The second line runs the SIGKILL storm and the four decoys (one of which reruns the storm) and may take longer than 30 s. Each line has its own `<fails_when>`, and both run inside the task. Do not widen any per-task `-R` beyond the task's own names.
- Real-time measurements appear only as the documented 2.0 s contract ceiling in non-sanitizer lanes; no other clock is evidence (D-105).
