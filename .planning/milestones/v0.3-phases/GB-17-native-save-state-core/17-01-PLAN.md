## Adopted wire contract — research A1/A2/A3 resolved

| Offset | Width | Field | Acceptance |
|---:|---:|---|---|
| 0 | 4 | magic | ASCII GBBS |
| 4 | 2 | format | LE u16 exactly 1 |
| 6 | 2 | header size | LE u16 exactly 64 |
| 8/10/12 | 2 each | release major/minor/patch | LE u16 0..65535, exact current CMake release |
| 14 | 2 | behavior | LE u16 exactly 1 |
| 16/17 | 1 each | profile/mode | exact loaded destination enum |
| 18 | 2 | reserved flags | zero |
| 20 | 32 | ROM SHA-256 | complete successfully loaded ROM |
| 52 | 4 | body size | LE u32 <=524288, exact descriptor size |
| 56 | 4 | total size | LE u32 exactly 64+body <=524352 |
| 60 | 4 | CRC | LE CRC-32/ISO-HDLC over bytes 0..59 then body |

CRC: reflected polynomial 0xEDB88320, init 0xFFFFFFFF, reflected input/output, final XOR 0xFFFFFFFF; 123456789 -> 0xCBF43926. Exclude checksum bytes; CRC detects corruption, never authenticates content. Body order: cart RAM; mutable mapper/rumble/RTC; WRAM/HRAM/VRAM/OAM/CRAM/banks; both frame pairs/palette/metadata; OAM DMA/HDMA; CPU/IRQ/timer/divider/serial/time; count and all 64 input slots; APU/register/sequencer/sample/ring/mix/HPF. Scalar widths/order are explicit in STATE_FIELDS and the format ledger. Ordinary times <=2^62; timer_reloaded_at UINT64_MAX is the separately validated sentinel. Plan 17-04 completes all-path operational horizon proof before final qualification.

The leading task extends the already-integrated compiled core/package tracer with pre-codec executable proof gates; Task 2 completes the new installed state API path in this same plan. New files: verify-state-contract.py, test_state_api.c and docs/state-format.md; all other listed paths are tracked. Every test must enter expected-tests in its creation task.
