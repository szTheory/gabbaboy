## Accomplishments

- Receipt consumption now requires `--repo`, resolves the frozen tag independently, and compares every archive path and blob to that Git tree. Unbound historical receipts remain parseable but cannot qualify.
- Source identity now hashes normalized byte paths, file content digests, symlink targets, and Git executable/link modes. The compressed archive digest remains provenance, so a re-encoded gzip of the same tree passes.
- Symlink resolution accounts for wrapped source archives and unwrapped product archives separately. In-root nested links pass source inspection, root escapes reject, and product archives still prohibit links.
