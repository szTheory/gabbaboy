## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Refusal-message pin cannot be a require_call**
- **Found during:** Task 1
- **Issue:** The macOS and Windows candidate-selection steps use the double-parenthesis arithmetic command, which the policy shell reader rejects as a subshell, so `require_call` sees no events for them.
- **Fix:** Added the `step-lines` presence item (parsed step, comments ignored, unconditional errexit step, echo followed by `exit 1`). Mutation W6-11b rejects it through the CLI.
- **Files modified:** .github/scripts/verify-workflow-policy.py
- **Commit:** af4aadc

**2. [Rule 3 - Blocking] api_commit and draft pinned as assignments**
- **Found during:** Task 1
- **Issue:** The one-line `|| { echo; exit 1; }` guard makes the shell reader record only the echo as the guard, so a required comparison call would be judged failure-ignoring (the limitation 15.1-23 recorded).
- **Fix:** Pinned the `api_commit=$(...)` and `draft=$(...)` assignments, which is strictly stronger than the old substring literals but does not prove the following comparison. Not fixed in the parser (out of this plan's ownership).
- **Files modified:** .github/scripts/verify-workflow-policy.py
- **Commit:** af4aadc

**3. [Rule 2 - Missing critical] Extra route and bite controls**
- **Found during:** Task 2
- **Issue:** A missing-sidecar run on the helper alone does not prove the draft/final gates route through it.
- **Fix:** Added an inventory_fixture `sidecar` defect run through `check_asset_inventory`, and a bite control on the v0.2 evidence CLI control.
- **Files modified:** .github/scripts/verify-release-gates.sh
- **Commit:** 0054c59

**Total deviations:** 3 (2 Rule 3, 1 Rule 2). **Impact:** none on plan goals; every removed pin has a named replacement.
