<assumption_delta_decision>
noun: frame output format per profile
decision: add-alongside
rationale: gbb_copy_frame keeps its uint8_t shade buffer byte-identical for the DMG profile and keeps GBB_UNSUPPORTED_PROFILE on the CGB profile (D-16, Phase 10 GATE-57); colour is added as a separate call gbb_copy_frame_rgb555 that serves only the CGB profile (D-02, D-15). Two independent stores mean the DMG pixel pipeline and its frozen baselines do not move, and neither caller has to branch on a format flag.
promote_when: a later milestone wants RGB555 on the DMG profile with a host DMG palette (CONTEXT Deferred Ideas). That is an additive widening of gbb_copy_frame_rgb555's profile gate, not a change to gbb_copy_frame; replacing the shade call would require a deprecation cycle and is not planned.
</assumption_delta_decision>
