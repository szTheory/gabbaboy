## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| save file saved_at -> catch-up | A stored timestamp decides how far the clock moves |
| command line -> clock override | A test flag could alter game time |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-31 | Spoofing | --clock-unix in normal play | medium | mitigate | Accepted only with battery smoke modes; strict int64 parse; player_session_clock_flag_scope negative cases; no environment variable |
| T-09-32 | Tampering | rollback or future timestamps | medium | mitigate | Policy never moves the clock backwards; rollback and no-clock scenarios assert unchanged totals and file bytes |
| T-09-33 | Tampering | repeated catch-up | medium | mitigate | catch_up_done flag per open; generation bump re-stamps on the next save; delta test cancels emulated time |
| T-09-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager install in this plan |
</threat_model>
